## Screenshots

Store the files in the kit folder and name them by slot:

- home-hero: the home page hero section
- pricing: the pricing page, when one exists
- feature-core: each core feature page, one shot each

Use clean full-page captures at a standard desktop size. Capture the product's own pages, never sample output or gallery images from inside the product.
